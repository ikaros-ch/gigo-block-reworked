# Ir sensor

True when the IR sensor sees an obstacle in front of it.

```sig
sensors.irSensor(sensors.SensorPortList.P1)
```

## Parameters

* **pinout**: the port the IR sensor is plugged into

## Example

```blocks
sensors.irSensor(sensors.SensorPortList.P1)
```
