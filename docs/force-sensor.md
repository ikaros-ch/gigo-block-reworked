# Force sensor

True while the force sensor is pressed.

```sig
sensors.forceSensor(sensors.DualPortList.E)
```

## Parameters

* **port**: the dual port the force sensor is plugged into

## Example

```blocks
sensors.forceSensor(sensors.DualPortList.E)
```
